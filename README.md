# The Coding Journey

Landing page for a coding-education brand: services, banners, newsletter subscribe, join CTA, and footer. Scroll animations use AOS.

**Live demo:** [the-coding-journey-lovat.vercel.app](https://the-coding-journey-lovat.vercel.app)

## Features

- Hero, services, and promotional banners
- Subscribe and join sections
- AOS scroll animations
- Responsive Tailwind CSS v4 layout

## Tech stack

| Area | Tools |
| --- | --- |
| UI | React 19 |
| Styling | Tailwind CSS 4 |
| Animation | AOS |
| Bundler | Vite 8 |
| Icons | react-icons |

## Getting started

```bash
git clone https://github.com/darksnake288-pixel/The-Coding-Journey.git
cd The-Coding-Journey
npm install
npm run dev
```

| Script | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
